# Screenshots

這個目錄保留給 App 畫面截圖。目前沒有包含任何截圖，因此 README 不放圖片連結。

後續可以加入（命名建議）：

| 檔名 | 內容 |
| --- | --- |
| `app_overview.png` | 手動輸入畫面與分析按鈕 |
| `safe_result.png` | ALLOW 結果與證據面板 |
| `review_result.png` | REVIEW 結果與原因代碼 |
| `block_result.png` | BLOCK 結果（無繼續按鈕） |

截圖注意事項：

- 只使用合成 fixture（`example.com`、`.test`、`.example` 等）。
- 不要拍到裝置序號、通知內容、其他 App 或個人資訊。
- 不建議開啟真實惡意網址後截圖；離線分析畫面即可。
